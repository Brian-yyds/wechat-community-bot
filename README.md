# wechat-community-bot

本地运行的「交易会员群」维护工具。功能仅限：定时公告、群消息整理识别（需全量抓取）、自动回复。

明确禁止：博彩 / 六合彩 / 下注结算 / 收款及相关功能。

完整调研与方案见 [PLAN.md](./PLAN.md)。文首为 2026-11-11 第三次调研（商用/闲鱼方案反查），其后为第二次全网与 X 调研；第一次含企业微信的调研在附录 A。
