## 当前自报（第一阶段）

- 协议类型：`mock`（本地模拟，`MockAdapter`）
- 配置项：`wechat.protocol = mock`，`wechat.protocol_type = mock`
- 框架或库名称与版本：无真实微信协议依赖；运行时只用 Python 标准库（可选 pyyaml）
- 登录态：无。消息由脚本、文件或标准输入注入，发送只记录在内存，不触达微信
- 已知检测与封号风险：
  - 当前不登录任何微信账号，因此没有真实封号路径
  - 若后续改为 Hook / Web / iPad / Windows / Mac 等非官方通道，将面临易被检测、限制登录设备、频繁二次验证，以及可能违反使用条款等风险；届时必须更新本文件「实际采用」一段，而不是沿用 Mock 自报
- 已具备、且与协议无关的降低风险措施：
  - 单群与全局发送频率上限，公告与自动回复分开配额
  - 拟人延迟默认 2–6 秒（下限不得低于 1.5 秒）
  - 夜间静默默认开启（00:30–07:00，Asia/Shanghai）：不主动发公告（可暂存），自动回复默认丢弃、不排队补发
  - 定时公告默认抖动 ≤3 秒，保证落在准点 ±5 秒内
  - 同内容冷却，避免重复刷屏
- 未采用的协议：Hook、Web、iPad、Windows/Mac、任何官方或第三方登录框架（第一阶段均未接入）
- 日期：2026-11-11

## 可选自报（启用 `wechat.inbound = local_capture` 时）

- 协议类型：其他（Windows 官方 PC 微信 4.x 本地库**只读**增量抓取；不注入、不 Hook、不模拟登录协议）。完整说明见 `docs/ADAPTER_A.md`。
- 框架或库名称与版本：本仓库 `LocalCaptureAdapter` / `LocalDbReader`；底层为 Python 标准库 `sqlite3` 只读 URI。不内置密钥提取或解密实现。
- 登录态如何获取与刷新：不另建登录态。依赖用户在 Windows 上已登录的官方客户端把消息同步到本机；本适配器只读打开用户提供的已解密 SQLite 副本或明文库。密钥若需要，只从环境变量或本地文件读取，绝不入库、绝不打印。
- 已知检测与封号风险：
  - 是否容易被官方检测：检测面小于 Hook / 协议号，但非零。反例：2026-06-17 有用户用 `wx-cli` 本地解密 WCDB 做统计，当天被提示「使用非官方客户端/外挂」并风控封号。
  - 登录设备数或登录方式限制：应固定一台家庭网络中的 Windows 与专用小号；云主机、频繁换机风险更高。
  - 验证码 / 二次验证频率：只读阶段较低，但不能排除完整性/异常环境检测。
  - 是否可能违反微信使用条款：是。《微信个人账号使用规范》2026-10-15 第 1.2.6 条禁止第三方对微信数据的访问读取。腾讯 2026-01 通过 GitHub DMCA 批量下架解密/导出类仓库；PyWxDump 于 2025-10 因律师函删库。
  - 群发、频繁主动私聊、跨群同步等行为限制：本适配器不发送；发送须另走限速与拟人层。
- 拟采用的降低风险措施：专用小号、家庭网络、先只读观察 7–14 天；单群/全局限频、拟人延迟 2–6 秒、夜间静默、公告抖动 ≤3 秒、同内容冷却（发送侧）。
- 未采用的协议及原因：Hook、iPad/Pad 协议、网页协议、模拟器多开（封号与合规风险更高）。UIA 发送、通知唤醒、OCR 降级为并行扩展点，不在本适配器内。
- 填写人与日期：微信群开发，2026-11-11。



## 适配器 B 自报（可选，`wechat.outbound = uia`）

默认示例配置仍是 `mock`。仅当用户在 Windows 上启用 UIA 发送时采用下列说明。完整部署与公开案例见 [ADAPTER_B.md](ADAPTER_B.md)。

- 协议类型：Windows 官方 PC 客户端 UI Automation（不注入进程、不模拟登录协议）
- 框架或库：尽力使用 `pyweixin`（Hello-Mr-Crab/pywechat，跟微信 4.1）或 `pywinauto`；本仓库的 `PyWeixinDriver` **尚未在真实微信客户端上验收**
- 登录态：由用户在官方客户端人工登录专用小号；掉线后不自动重登，立即写入 `data/PAUSE` 并停止发送
- 已知检测与封号风险：
  - 违反《微信个人账号使用规范》（2026-10-15）中关于第三方自动化、访问或控制界面与数据的条款，不存在零封号方案
  - 2026-08 已有 pyweixin-rpa 导致禁止登录电脑、不常用号被踢下线的公开反馈（pywechat#296 等），详见 ADAPTER_B.md
  - 窗口不可见、锁屏、远程桌面断会话会使 UIA 停止；部分账号需开启「讲述人」
- 降低风险措施：发送必须走限速层（默认每小时 40 条、拟人延迟 2–6 秒、夜间静默）；适配器内另有输入停顿、切群间隔、单次最小间隔；失败不连重；紧急暂停；只用专用小号和家庭网络
- 延迟目标（仅计适配器自身耗时，不含限速层拟人延迟）：已打开会话 ≤ 3 秒，未打开会话 ≤ 8 秒
- 填写日期：2026-11-11
